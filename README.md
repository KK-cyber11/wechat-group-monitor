# 微信群监控

给准备使用的人。AI 看同目录的 `SKILL.md`。

## 你要做的事

1. 把这个文件夹下载到自己的 Mac 上。
2. 打开装在这台 Mac 上的 Codex、Claude Code，或能操作屏幕的 Grok。网页版和手机不行。
3. 让这个 AI 读文件夹里的 `SKILL.md`。
4. 打开微信并登录。要看的群留在左边列表里。
5. 对 AI 说：开始监控这些群。然后把群名发给它。不用说每 5 分钟，它会自己每 5 分钟看一次。只有你想改成别的时间，才需要另说。如果要盯某个人，再说：特别关注 xxx 群的李华。
6. AI 会自己去申请截屏和操作屏幕的权限。你只要在弹出的窗口里点允许。不用自己找设置。
7. 不用在微信里再授权。微信保持你自己登录即可。

做完以后，有新消息时，总结出现在你和 AI 的对话里，并写在这个群自己的 `summary.md`。没有新消息就不会发，也不会写文件。

关机再开机、登录之后，不用再对 AI 说话。微信和监控会自己打开，并从上次停下的地方接着采。

## 它会做什么

每 5 分钟用截屏看你指定的群。有新内容就总结。你点名之后，可以在群总结下面单独概括某个人说了什么。待机时不采集，登录后自动接着采，并补上待机期间漏掉的消息。不会在群里发消息。图片和视频只记屏幕上的样子，不保存原文件。

## 目前的问题

- 采集时会抢占屏幕。程序会轮流点开这些群，你正在看的画面会被切走，采完再切回来。
- 特别关注某人要你先说出来。不说，就只做整群总结。
